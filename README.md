## 👨‍💻 Sobre mim

Sou estudante de **Ciência de Dados na Faculdade SENAI**, com formação técnica em **Análise e Desenvolvimento de Sistemas (ADS)** pelo SENAI-SP.

Tenho interesse em explorar o potencial dos dados, desenvolver soluções inteligentes e transformar informações em conhecimento através da tecnologia.

Atualmente, venho aprofundando meus estudos em análise de dados, inteligência artificial e desenvolvimento de modelos de Machine Learning e Deep Learning.

- 🎓 Superior em Ciência de Dados — Faculdade SENAI.
- 💻 Técnico em Análise e Desenvolvimento de Sistemas.
- 📊 Data Science, Data Analytics e Business Intelligence.
- 🤖 Machine Learning, Deep Learning e Inteligência Artificial.
- 🌐 Desenvolvimento de sites e aplicações web.
- 🚀 Sempre aprendendo e desenvolvendo novos projetos.

## 🚀 Projetos em destaque

### 🌱 Inteligência de Dados Aplicada à Sustentabilidade

Projeto desenvolvido a partir de dados da ONG Limpa Brasil, com foco na análise territorial e identificação de padrões na coleta de resíduos urbanos.

**Tecnologias:** Python, Pandas, NumPy, Plotly e Streamlit.

### 🏆 Hackathon SENAI — Análise de Dados

Participação em um hackathon de 6 horas, desenvolvendo uma solução para um desafio de Recursos Humanos, envolvendo coleta, tratamento e visualização de dados. Projeto premiado com o **2º lugar**.

**Tecnologias:** Python, Web Scraping e Análise de Dados.

### 🤖 Machine Learning & Deep Learning

Projetos experimentais de aprendizado de máquina, redes neurais e inteligência artificial, explorando diferentes algoritmos e aplicações práticas.

**Tecnologias:** Python, Scikit-learn, TensorFlow e Keras.
